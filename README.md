# 🛍️ Full-Stack E-Commerce Website

A complete full-stack e-commerce web application with secure payment gateway integration. Users can register, browse products, manage their cart, and place orders. Admins can manage products, orders, and users via a dedicated dashboard.

## ✨ Features

- User authentication and authorization (JWT-based)
- Browse, filter, and search products
- Add to cart and manage cart items
- Secure checkout process
- Payment integration with Razorpay / Stripe
- Order history and details
- Admin panel:
  - Manage products
  - View and process orders
  - Manage users
- Mobile responsive UI

## 🛠️ Tech Stack

### 🔹 Frontend
- React JS
- React Router DOM
- Axios
- Tailwind CSS

### 🔸 Backend
- Node.js
- Express.js
- MongoDB with Mongoose
- JWT for authentication
- Stripe / Razorpay SDK
